TAJALALAPAK — FINAL RESPONSIVE FRONTEND
=======================================

Struktur folder:
- index.html                 Halaman utama
- assets/css/style.css       CSS kustom desktop/tablet/mobile
- assets/js/app.js           JavaScript interaksi
- assets/img/README.txt      Petunjuk aset gambar lokal

Bootstrap 5.3.3, Font Awesome 6.5.2, dan Google Fonts dimuat dari CDN,
jadi browser memerlukan koneksi internet untuk memuat library eksternal.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder tajalapak-final di VS Code.
3. Jalankan index.html dengan Live Server.
4. Untuk mengecek responsive, gunakan DevTools > Device Toolbar.

Catatan:
- Ini frontend demo; belum terhubung ke backend/database/API kurir.
- Gambar demo masih memakai URL eksternal. Folder assets/img tersedia untuk aset lokal.
